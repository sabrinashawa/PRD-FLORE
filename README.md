# PRD-Flore

# Product Requirements Document (PRD)

## Aplikasi Pencatat Haid Sederhana

## 1. Latar Belakang

Banyak pengguna sering lupa mencatat tanggal haid, gejala yang dirasakan, serta kondisi tubuh saat sedang haid. Hal ini membuat pengguna sulit mengetahui pola siklus haid dan perkiraan haid berikutnya. Aplikasi Flore dibuat untuk membantu pengguna mencatat dan memantau siklus haid secara sederhana, praktis, dan mudah digunakan.

## 2. Tujuan Produk

- Membantu pengguna mencatat tanggal mulai haid
- Membantu pengguna mencatat derasnya aliran haid
- Membantu pengguna mencatat suasana hati dan gejala yang dirasakan
- Menampilkan riwayat catatan haid
- Menampilkan kalender haid
- Memberikan prediksi tanggal haid berikutnya
- Menampilkan statistik sederhana berdasarkan data catatan haid

## 3. Target Pengguna

- Remaja atau mahasiswa yang ingin mencatat siklus haid
- Pengguna yang sering lupa tanggal haid terakhir
- Pengguna yang ingin mengetahui perkiraan haid berikutnya
- Pengguna yang ingin mencatat gejala dan suasana hati saat haid
- Pengguna yang membutuhkan aplikasi pencatat haid sederhana

## 4. Fitur Utama

1. **Beranda**

   - Menampilkan informasi ringkas siklus haid
   - Menampilkan status periode haid
   - Menampilkan tanggal haid terakhir
   - Menampilkan prediksi haid berikutnya
   - Menampilkan tombol Catat Baru

2. **Catat Haid**

   - Pengguna dapat memilih tanggal mulai haid
   - Pengguna dapat memilih derasnya aliran, yaitu ringan, sedang, atau deras
   - Pengguna dapat memilih suasana hati, seperti netral, senang, sedih, atau sensitif
   - Pengguna dapat memilih gejala, seperti kram, sakit kepala, kembung, mual, lelah, jerawat, dan nyeri punggung
   - Pengguna dapat menulis catatan tambahan
   - Pengguna dapat menyimpan catatan haid

3. **Riwayat Haid**

   - Menampilkan daftar catatan haid yang sudah disimpan
   - Menampilkan tanggal haid
   - Menampilkan derasnya aliran haid
   - Menampilkan suasana hati, gejala, dan catatan tambahan

4. **Kalender**

   - Menampilkan kalender bulanan
   - Menandai tanggal haid
   - Menandai tanggal prediksi haid
   - Menandai hari ini
   - Menampilkan legenda kalender

5. **Statistik**

   - Menampilkan total catatan haid
   - Menampilkan rata-rata durasi haid
   - Menampilkan rata-rata siklus
   - Menampilkan ringkasan suasana hati
   - Menampilkan gejala yang paling sering muncul

## 5. User Flow

1. Pengguna membuka aplikasi Flore
2. Pengguna masuk ke halaman beranda
3. Pengguna menekan tombol Catat Baru
4. Pengguna memilih tanggal mulai haid
5. Pengguna memilih derasnya aliran haid
6. Pengguna memilih suasana hati
7. Pengguna memilih gejala yang dirasakan
8. Pengguna menulis catatan tambahan jika diperlukan
9. Pengguna menekan tombol Simpan
10. Data tersimpan dan tampil di halaman riwayat
11. Kalender menampilkan tanggal haid yang sudah dicatat
12. Statistik menampilkan ringkasan berdasarkan data catatan

## 6. Kebutuhan Fungsional

- Aplikasi dapat menampilkan halaman beranda
- Aplikasi dapat menampilkan halaman catat haid
- Aplikasi dapat menyimpan tanggal mulai haid
- Aplikasi dapat menyimpan data derasnya aliran haid
- Aplikasi dapat menyimpan suasana hati pengguna
- Aplikasi dapat menyimpan gejala yang dipilih pengguna
- Aplikasi dapat menyimpan catatan tambahan
- Aplikasi dapat menampilkan riwayat catatan haid
- Aplikasi dapat menampilkan kalender haid
- Aplikasi dapat menampilkan statistik sederhana
- Aplikasi dapat menghitung prediksi haid berikutnya

## 7. Kebutuhan Non-Fungsional

- UI sederhana dan mudah digunakan
- Tampilan menggunakan warna lembut bernuansa pink kecokelatan
- Aplikasi berjalan di perangkat Android
- Aplikasi ringan dan dapat berpindah halaman dengan cepat
- Data digunakan untuk pencatatan pribadi pengguna
- Aplikasi belum membutuhkan koneksi internet untuk penggunaan dasar

## 8. Platform

- Mobile Android
- Flutter

## 9. Metode Pengembangan

- Menggunakan Flutter
- Data awal disimpan secara lokal atau sementara
- Prediksi haid menggunakan perhitungan siklus sederhana
- Tampilan dibuat minimalis agar mudah dipahami pengguna

## 10. Timeline Sederhana

- Minggu 1: Desain UI aplikasi
- Minggu 2: Implementasi fitur utama
- Minggu 3: Testing dan perbaikan aplikasi

## 11. Risiko

- Prediksi haid tidak selalu akurat karena siklus setiap pengguna dapat berubah
- Data bisa hilang jika aplikasi dihapus
- Belum tersedia fitur login dan backup data
- Belum tersedia fitur edit dan hapus catatan haid
- Pengguna perlu mengisi data secara manual agar riwayat tetap tercatat

## 12. Keberhasilan Produk

- Aplikasi berjalan tanpa error
- Pengguna dapat menambahkan catatan haid
- Pengguna dapat melihat riwayat catatan haid
- Kalender dapat menampilkan penanda tanggal haid
- Statistik dapat menampilkan ringkasan data catatan
- Aplikasi dapat menampilkan perkiraan haid berikutnya
- Tampilan aplikasi mudah dipahami oleh pengguna



PRD ini dibuat sederhana untuk kebutuhan tugas atau pengembangan awal aplikasi Flore.
